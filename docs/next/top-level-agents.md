# All and Top-level Agents

Click **agents · All** in the expanded sidebar to switch to **Top-level**. Click again to show all agents. The global menu also has **Toggle top-level**; the mobile switcher offers the same control, including when the filtered list is empty. The collapsed sidebar footer still only expands the sidebar.

Top-level hides agents in linked worktree workspaces when the same endpoint has a non-linked parent workspace with the same worktree key. It keeps every parent agent, standalone workspace, workspace without grouping metadata, and orphan worktree whose parent is absent. Identical keys on different machines do not form a group.

A collapsed, focused-out, or snoozed parent still counts as present. Hiding its row does not promote its children. Focus, shared Snooze, externally controlled agent views, and agent ordering continue to apply.

The mode affects the Agents list, its click targets, numbered agent shortcuts, and next/previous agent navigation. Spaces, tabs, panes, notifications, approvals, and running processes are unchanged. Each client starts in All; changing the mode neither persists a preference nor changes another client.
